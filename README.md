# Turkish Learning Platform

## About this project

I am building a personal Turkish learning platform while learning GitHub and project management.

The goal is to create a website that helps me learn Turkish through vocabulary, grammar, quizzes, flashcards and practical conversations.

At the same time, I am using this project to develop practical skills in project management and digital development.

## Project goals

- Learn how to use GitHub professionally.
- Understand project management workflows.
- Build a website using HTML, CSS and JavaScript.
- Create an interactive Turkish learning environment.
- Track learning progress and vocabulary.
- Eventually expand the website into a mobile application.
